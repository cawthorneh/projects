LCRA relay diagnostic

The rainfall components read LCRA Hydromet through public CORS relays, and those relays are failing on the live site. This tests each link in the chain from this browser, on this network, and reports exactly what each one does.

Nothing is sent anywhere. Every request goes straight from this page to LCRA or a relay, exactly as the components do. Opening this from your desktop tests whether the relays are alive at all; putting it on a page of the site tests the same thing from the site's own origin, which is what actually matters if the relays turn out to be fine here.
