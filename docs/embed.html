Water news dashboard — embed reference

Paste the snippet below into a Webflow Embed element on the Water News page. The iframe reports its own height, so the widget grows and shrinks with the story count instead of scrolling inside a fixed box.

Snippet

<div style="max-width:1180px;margin:0 auto">
  <iframe
    id="drw-water-news"
    src="https://cawthorneh.github.io/projects/news.html?embed=1"
    title="Water news dashboard"
    loading="lazy"
    style="width:100%;border:0;display:block;height:1200px"
    scrolling="no"></iframe>
</div>
<script>
(function () {
  var frame = document.getElementById("drw-water-news");
  var origin = "https://cawthorneh.github.io";
  window.addEventListener("message", function (e) {
    if (e.origin !== origin) return;                  // ignore everyone else
    if (!e.data || e.data.type !== "drw-news-height") return;
    frame.style.height = e.data.height + "px";
  });
  // Ask for a height once the frame is up, in case we missed the first message.
  frame.addEventListener("load", function () {
    frame.contentWindow.postMessage({ type: "drw-news-measure" }, origin);
  });
})();
</script>
Replace cawthorneh.github.io/projects with the real Pages URL if the repository is renamed or moved to a custom domain — it appears twice (the src and the origin check).

URL options

Append these to the iframe src to change what the widget shows.

ParameterEffect
embed=1Drops the page background and outer padding so the widget sits flush on your page. Always use this in an iframe.
category=localOpen on one topic: local, research, policy, or positive. Visitors can still switch.
limit=6Cap how many stories render. Good for a teaser block on the homepage.
featured=0Turn off the wide lead-story treatment; render an even grid instead.
header=0Hide the built-in heading block and use your own Webflow headline above the embed.
footer=0Hide the source list and attribution line.
heading=…Replace the headline text (URL-encoded).
eyebrow=…Replace the small gold label above the headline.
lede=…Replace the paragraph under the headline.
q=cisternPre-fill the search box.
accent=%233066ABOverride the primary colour (URL-encode the # as %23).
font=PoppinsPrepend a font family, if the site loads one the iframe can also reach.

Homepage teaser variant

Six stories, no lead card, your own headline above it:

src="…/news.html?embed=1&limit=6&featured=0&header=0&footer=0"
